First release of Okapi by JRNY. Separate Profiles, each with its own cookies, Tabs, history, bookmarks and downloads, so one site can hold a different account in each. Move a Tab to another Profile or open it there. Site Rules send links from other apps to the Profile you chose. Also: Pinned Tabs and Folders, Private Tabs, a Start Page, a Sidebar in wide windows and a Bottom Bar in narrow ones, and Google, Bing, DuckDuckGo or Brave Search. Passkeys and Custom Tabs are not supported yet.
